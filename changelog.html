Changelog

Every released version of Fold EQ, newest first

Updates inside version 1 are free if you have bought Fold EQ — the same licence file keeps working, so there is nothing to re-enter. Older builds stay downloadable here in case a session needs the exact version it was made with.

Version 1.1

Current 27 August 2026

  • Offline renders now sound the same as real-time playback. Filter movement and modulation used to step in fast bounces, especially on moving high and low cuts. Fixed.
  • New Audio Unit version on macOS, so Fold EQ now runs in Logic Pro and GarageBand.
  • New option in the gear menu, GPU-accelerated UI (OpenGL). Off by default. Turn it on if the interface feels laggy in your DAW, which has been reported in Ableton on some Windows machines.
  • No changes to sound, presets, or parameters in normal playback. Your sessions and licences work exactly as before.
  • Windows installer 6.9 MB
  • macOS installer 9.2 MB

Checking a download

Both installers are code signed, so Windows and macOS verify them before they run. If you want to check a file yourself, the SHA-256 hashes for the current release are on the downloads page.

Something broken in a new version?

Email support@ridgesound.com with your operating system, your DAW and the version you were on before. You can reinstall an older build from this page at any time — installing over the top is enough, there is no need to uninstall first.
