2. What we sell

We sell audio plugins. These are small pieces of software that run inside music production applications such as Ableton Live, FL Studio, Cubase, Reaper and Studio One. These applications are commonly called DAWs (digital audio workstations). A plugin is not a standalone program you buy and run on its own; it loads inside your DAW and processes sound as it passes through.

Our plugins are supplied in the VST3 format only, on both Windows and macOS. You need a DAW that supports VST3 in order to use what you buy. Logic Pro and GarageBand load only Audio Units, and Pro Tools loads only AAX, so our plugins do not run in them. Please check that your DAW supports VST3 before buying, and use the free demo to confirm.

Everything we sell is downloadable software. There is no physical product, and nothing is shipped to you.
