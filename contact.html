Common questions

It says DEMO MODE but I paid

The license file has not been loaded yet. Buying does not unlock the plugin by itself — you download a license file and load it once. Open the plugin, click the gear icon, choose Load License, and select the .foldeqlicense file you downloaded. It unlocks immediately, with no restart.

I lost my license file

Nothing is lost. Go back to the license portal linked on your Paddle receipt, enter your order reference and the email address you bought with, and download it again. You can do this as many times as you like, forever. If you cannot find the receipt, email me and I will look it up.

Where does the license file live?

Once loaded, the plugin stores it at:

  • Windows — %APPDATA%\RidgeSound\license.foldeqlicense
  • macOS — ~/Library/Application Support/RidgeSound/license.foldeqlicense

How many computers can I install on?

As many as you personally own or control. There is no activation limit, no machine binding, and no online check. If you have a studio machine and a laptop, use both. If you replace your computer, just load the same license file on the new one.

Do the plugins phone home?

No. Licenses verify offline using cryptography built into the plugin. Ridge Sound plugins make no network connections at all — they work on a machine that has never been online.

Can I use it on commercial releases?

Yes. Any audio you make is entirely yours, with no royalty and no credit required.
