FOLD EQ

Downloads

Last updated 23 August 2026  /  Los Angeles, California

One installer per platform, and it is the same file whether you have bought a licence or not. Without a licence it runs in demo mode. Load a licence file and it unlocks in place, with no reinstall and no restart.

Windows

Download for Windows

  • Size 6.7 MB
  • Needs Windows 10 or 11, 64-bit
  • Installs VST3, plus an optional standalone app
  • Signed Yes. Azure Trusted Signing, timestamped.

macOS

Download for macOS

  • Size 4.8 MB
  • Needs macOS 10.13 or later
  • Installs VST3 and Audio Unit. Universal, Intel and Apple Silicon.
  • Signed Yes. Developer ID, notarized and stapled.

What demo mode does

Everything works. Every control, every preset, no time limit, no saved-project restrictions. The only difference is that the audio output mutes for about two seconds every twenty-five seconds, and the splash line reads DEMO MODE instead of your name. Run it on real sessions for as long as you want before deciding.

Installing

Windows

Run the installer. It asks for administrator rights because the VST3 goes into the shared plugin folder at C:\Program Files\Common Files\VST3. Factory presets land in your Documents folder. Restart your DAW afterwards and rescan plugins if it does not pick up Fold EQ on its own.

macOS

Open the .pkg and follow the prompts. The VST3 goes to /Library/Audio/Plug-Ins/VST3 and the Audio Unit to /Library/Audio/Plug-Ins/Components. Logic and GarageBand only rescan Audio Units at launch, so quit and reopen them rather than just closing the project.

Unlocking your copy

If you have bought Fold EQ, go to the licence portal with the order reference from your Paddle receipt and download your licence file. Then open Fold EQ, click the gear icon, choose Load Licence, and pick the .foldeqlicense file. The splash line changes from DEMO MODE to your name straight away.

You can install on as many computers as you own. There is no activation count, no machine binding, and the plugin never contacts us. It verifies the licence offline, so it works on a machine that has never been online.
