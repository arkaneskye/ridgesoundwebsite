What demo mode does

Everything works. Every control, every preset, no time limit, no saved-project restrictions. The only difference is that the audio output mutes for about two seconds every twenty-five seconds, and the splash line reads DEMO MODE instead of your name. Run it on real sessions for as long as you want before deciding.

Installing

Windows

Run the installer. It asks for administrator rights because the VST3 goes into the shared plugin folder at C:\Program Files\Common Files\VST3. Factory presets land in your Documents folder. Restart your DAW afterwards and rescan plugins if it does not pick up Fold EQ on its own.

macOS

Open the .pkg and follow the prompts. The VST3 goes to /Library/Audio/Plug-Ins/VST3. Restart your DAW afterwards and rescan plugins if it does not pick up Fold EQ on its own.

Fold EQ installs as VST3 on both platforms, and as an Audio Unit on macOS. That means Logic Pro and GarageBand work from version 1.1 onward. The one DAW it cannot run in is Pro Tools, which loads only AAX. If you are on Windows you need a DAW that loads VST3, which is nearly all of them.

Unlocking your copy

If you have bought Fold EQ, go to the licence portal with the order reference from your Paddle receipt and download your licence file. You can do that as many times as you like, whenever you like. Then open Fold EQ, click the gear icon, choose Load Licence, and pick the .foldeqlicense file. The splash line changes from DEMO MODE to your name straight away.

You can install on as many computers as you own. There is no activation count, no machine binding, and the plugin never contacts us. It verifies the licence offline, so it works on a machine that has never been online.
